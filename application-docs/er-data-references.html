ER Diagram — Data References

โมเดลพื้นฐานสำหรับหน้า Data References (แผนก / ประเภทปัญหา / ทักษะ IT) และจุดเชื่อมต่อไปยัง Ticket กับ User ซึ่งหน้าอื่นจะอ้างอิงค่าเดียวกันแทน hard-code / enum

Scope: foundation first UI catalogs: departments · categories · skills Target DB: PostgreSQL + Prisma

2. ตารางหลักของ Data References

REFERENCE_CATALOG

ชุด master ของแต่ละ dropdown / catalog ในหน้า References

ColumnNotes
idPK (cuid)
codeUK — departments | categories | skills
name_th / name_enชื่อแสดง catalog
created_at / updated_ataudit timestamps

REFERENCE_ITEM

รายการใน catalog — ตรงกับแถวในตาราง UI ปัจจุบัน

ColumnNotes
idPK (cuid)
catalog_idFK → REFERENCE_CATALOG
codeUK คู่กับ catalog (เช่น account, hardware)
label_th / label_enข้อความแสดงผล TH/EN
iconnullable — Material icon (categories / skills)
is_activeซ่อนจาก dropdown แต่ยังอ้างอิงประวัติได้
sort_orderลำดับใน UI

Constraint แนะนำ: UNIQUE (catalog_id, code) และ index (catalog_id, is_active, sort_order) สำหรับ list API

3. จุดเชื่อมกับโดเมนอื่น (foundation consumers)

  • Ticket.category_item_id → REFERENCE_ITEM ที่อยู่ใน catalog categories — แทน enum TicketCategory ใน Prisma ปัจจุบัน
  • Ticket requester department → REFERENCE_ITEM catalog departments — เก็บบน snapshot ผู้แจ้ง (guest ไม่ต้อง login) ไม่บังคับผูก User.department
  • USER_SKILL (M:N) → User ↔ REFERENCE_ITEM catalog skills — รองรับการจับคู่ทักษะกับผู้รับผิดชอบภายหลัง

หมายเหตุเทียบ schema ปัจจุบัน: apps/api/prisma/schema.prisma ยังใช้ Ticket.category เป็น enum และ User.department เป็น string — เอกสารนี้คือเป้าหมายเมื่อต่อ API Data References ก่อน แล้วค่อย migrate consumer

4. Seed catalogs (ตรงกับ UI)

catalog.code ใช้ที่ไหน ฟิลด์พิเศษของ item
departments ฟอร์มแจ้งเคส (แผนก), filter/รายงาน ไม่มี icon
categories ฟอร์มแจ้งเคส (ประเภทปัญหา), การ์ดบนกระดาน icon (Material)
skills โปรไฟล์ / ความเชี่ยวชาญ IT staff icon (Material)

5. API surface ที่เสนอ (ขั้นถัดไป)

MethodPathAuthหน้าที่
GET /references/catalogs IT session รายการ catalog + จำนวน item
GET /references/:catalogCode/items IT / หรือ public read active list items (query: activeOnly)
POST /references/:catalogCode/items IT session สร้าง item
PATCH /references/items/:id IT session แก้ label / icon / sort / active
DELETE /references/items/:id IT session soft-delete หรือปฏิเสธถ้ายังถูกอ้างอิง

Guest ฟอร์มแจ้งเคสควรอ่านได้เฉพาะ item ที่ is_active = true (endpoint read คู่ขนานหรือ query flag) — CRUD เต็มรูปแบบเฉพาะ IT ตาม ADR 0002
